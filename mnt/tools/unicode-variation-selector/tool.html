How it works:

This tool uses Unicode variation selectors (invisible characters) to hide text within normal-looking text. Each character in the hidden message is encoded as a variation selector attached to a character in the visible text.

Note: You can hide messages of any length with any number of visible characters - the tool will distribute the hidden characters across the visible text. However, having too many hidden characters per visible character might affect compatibility with some systems.
